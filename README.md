# jatinmomaya.com

Personal site. Starter scaffold — the design comes later.

## How publishing works

1. Edit files in this folder.
2. Commit and push to the `main` branch on GitHub.
3. Vercel watches the repo and redeploys automatically. Live in about a minute.

No servers, no FTP, no manual uploads. Push code, get website.

## Structure

- `index.html` — home page
- `styles.css` — all styles (for now)
