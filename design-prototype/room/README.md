# Jatin Momaya room prototype

A static homepage design experiment for jatinmomaya.com. Open `index.html` directly in a browser. It has no dependencies or build step.

The room, shelves, art, lamp, and books make up one scene. The top-shelf books are navigation. When selected, the whole book should turn toward the visitor as nearby books shift aside. The lower books are decorative for now.

This version is an unfinished starting point and is not approved. Keep edits in this folder on `design/room-prototype`. Do not change the site files at the repository root, merge to `main`, or deploy without Jatin’s explicit approval.

Read [DESIGN_NOTES.md](DESIGN_NOTES.md) for the visual rationale and [MUSE_HANDOFF.md](MUSE_HANDOFF.md) for continuation instructions.
